# Epistemics rules (hard gates, not voice)

1. Every quotation mark encloses words that appear verbatim in a source we fetched. No paraphrase
   in quotes, no stitching two sentences into one quote, no cleaning up grammar inside quotes.
2. Every number appears in a source we fetched, in the same form or an obvious equivalent
   (3,000 / 3000). No rounding that changes the claim. No arithmetic the source didn't do.
3. Dates are explicit ("on Oct 14"), never "yesterday" or "this week" inside a slide.
4. One-source claims get "reportedly", "according to <outlet>", or "the states say".
5. Superlatives and firsts ("largest ever", "first time") only when a source says so.
6. If the sources don't say it, we don't know it. Leave it out rather than guess.
